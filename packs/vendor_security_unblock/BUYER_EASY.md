# 买家极简手册（转发给对方即可）

你不需要开会。按顺序点/复制即可。

## 一页入口

**https://marksoc-180.github.io/agentgate/easy.html**  
（push 部署后生效；本地可打开 `web/easy.html`）

上面所有回复都是「点一下复制 → 粘贴到邮件」。

## 你最少要做的事

| 何时 | 你做什么 | 字数 |
|------|----------|------|
| 收到问诊信 | 回 YES / NO / NOT SURE 一行 | 1 行 |
| 若 YES | 可选：点一下最疼的点 | 1 行 |
| 若匹配想继续 | 回 `Send SOW` | 1 行 |
| 收到 SOW | 按发票付款（或回 billing 邮箱） | 付款操作 |
| 付款后 | 填进件（有模板，可复制） | 几行 |

## 付款后进件（复制填空）

```
Company:
Environment (VPC / k8s / laptop PoC):
MCP / tools in scope:
Questionnaire file: (attach)
Deadline:
Billing entity / invoice email:
```

## 我们保证的方便

- 默认不开会  
- 一个 SOW、一种产品  
- 工作日 48h 内邮件回复  
- 交付是现成文件夹，不是口头承诺  
- 不匹配回 `pass` 即结束，无人追着磨
