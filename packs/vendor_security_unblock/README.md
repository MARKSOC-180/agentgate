# Vendor Security Unblock Pack（交付模板）

> **这是产品缺口补齐：** 对方要的不只是 Docker，而是「问卷怎么答 + 附什么证据」。  
> Design Partner 交付时：复制本目录 → 按客户改 `{COMPANY}` / 策略摘录 → 放进 `pilot_deliver` 输出包。

## 内容

| 文件 | 用途 |
|------|------|
| `QUESTION_BANK.md` | 常见企业安全问卷 · Agent/MCP 相关题 · 草稿答法 |
| `EVIDENCE_MAP.md` | 每题对应附哪个导出文件 |
| `CUSTOMER_INTAKE.md` | 开工前向客户要的最少信息（邮件即可） |

## 不做虚假承诺

- 不生成假 SOC2 / 假渗透报告  
- 只覆盖 **agent 工具调用 / MCP / 审计 / 人在环 / 数据出墙** 相关条目  
- 其余条目标注 `OUT_OF_SCOPE — use your existing Corp Sec answers`
